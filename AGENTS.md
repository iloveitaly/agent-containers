# Agent notes

## Cursor Cloud specific instructions

- `install` + `start` only (no Dockerfile).
- Keep [`.cursor/environment.json`](.cursor/environment.json) as `curl | bash` against `master`. Copy-paste for other projects; do not use `bash cursor/install.sh`.
- [`cursor/Dockerfile`](cursor/Dockerfile) is the Cursor-like base (`locales`, `xz-utils`, `tmux`, `python3`, `jq`, `ripgrep`, `unzip`, `git`, `sudo`). [`cursor/install.sh`](cursor/install.sh) is the overlay: Docker/mise/direnv, `libnss3-tools` (`certutil`) when missing plus an empty `~/.pki/nssdb` for the `ubuntu` user, system mise config under `/etc/mise` (`uv`, `gh` only if missing, `MISE_ENV=dev,extras` in `/etc/mise/miserc.toml` + `/etc/zsh/zshenv` + `/etc/environment`, assumed [python-starter-template](https://github.com/iloveitaly/python-starter-template/) `.config/mise.dev.toml` / `.config/mise.extras.toml`), idempotent edits via global mise `pypi:lineinfile@latest` (all `mise install` / `mise exec` as `ubuntu`, never root), and `iloveitaly/gh-ai-pr` via passwordless sudo. If `$PWD` has a `.envrc`, it runs `direnv allow` as `ubuntu`. If `$PWD` has a justfile, `mise which just` succeeds, and `setup` is defined, it runs `just setup --skip-services` as `ubuntu` via `mise exec -- direnv exec .` when `just --usage setup` lists that flag (otherwise `just setup`). It does not install `just` itself. After that setup it runs [`iloveitaly/dotfiles`](https://github.com/iloveitaly/dotfiles) `install/linux-devbox.sh` as `ubuntu` (`DOTFILES_REF`, default `master`; `TERM=xterm-256color` so `zinit update` is not skipped; `MISE_DISABLE_TOOLS` keeps the linux.toml compiler disables and also skips `ast-grep`, `node`, `python`, `azure-cli`, and `aiautocommit`, which do not install on this glibc image under that musl setting). Mise is already at `/usr/local/bin/mise`, so that script does not install another copy. The rsync replaces `~/.config/direnv/direnv.toml`; install.sh then puts the `/workspace` whitelist back beside `strict_env`. `/etc/mise` and `/etc/zsh/zshenv` are left as they are. `linux-devbox.sh` installs `just` globally, so both `install.sh` and `start.sh` run `just setup` only when the project mise config (`mise.toml`, `.mise.toml`, or `.config/mise.toml`) declares `just`. `OP_INTEGRATION_DISABLED=1` is set only in the install process environment (not persisted, not used by `start.sh`) so `op` does not wait on the 1Password app during snapshot setup. That `--skip-services` run is the environment snapshot. [`cursor/start.sh`](cursor/start.sh) starts dockerd on every container run, then runs `just setup` as `ubuntu` through the same `mise exec -- direnv exec .` path when a setup recipe exists and the project declares `just`.
